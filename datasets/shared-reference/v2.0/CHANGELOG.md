# CoA Shared Database v2.0.0
## Added
- Eight provenance-labeled core datasets rebuilt from existing archived v1.2 source extracts.
- Class/spec/talent/spell relationship graph with explicit source evidence, missing references and conflict report.
- Archived encounter credit overlay; **not** verified boss mechanics or live timers.
- Five Lua 5.1-style addon projections; candidates are not live-game claims.
- Research Explorer with search and source-status detail; site index generated by CI.
- Reproducible validation, SHA-256 manifest, verified release ZIP.
## Unresolved
- No verified summon spell -> NPC -> owner -> pet ability chains.
- Questie-X positional Lua schema, coordinates and quest joins not independently validated.
- No verified creature drop tables, vendor/recipe joins, equipment restrictions or trainer mappings.
- Charlga and hostile trash AI, live combat GUID traces, custom client APIs and addon UI compatibility require trustworthy evidence or runtime tests.
- Site deployment must be checked independently; publication of a search index does not guarantee a live deployment.
